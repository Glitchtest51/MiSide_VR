MiSide_VR
=====
A work-in-progress mod to make **MiSide** playable in VR, written in BepinEx.

Status
=====
- Renders and displays in the headset.
- Controller tracking + Basic Input.
- WIP Not Playable.

How to use
=====
This mod is currently not playable.

Contributions and Donations
=====
Contributions are off until the mod reaches a playable stage, any pull requests and issues made will be closed.

Donations are currently not open, if you like or find this project helpful please star the repository.
